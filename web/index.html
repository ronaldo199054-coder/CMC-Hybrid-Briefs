CMC Hybrid Briefs

Plain-language crypto briefs from live CoinMarketCap data. The verdict is written by generative AI through Firebase AI Logic — on-device (Gemini Nano 4) when it can, cloud (Gemini) when it must. Every number comes from the brief, never from the model.
